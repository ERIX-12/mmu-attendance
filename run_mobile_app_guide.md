# 📱 Running the MMU Student Attendance Mobile App

This guide walks you through setting up and running the Flutter mobile application for the **Mountains of the Moon University (MMU) Student Attendance System**. 

The app is built using **Flutter** and is designed to work seamlessly with the backend. By default, it is configured to connect directly to the **production backend on Render**, meaning **you do not need to run a local backend** to test or run the mobile app!

---

## 🛠️ Step 1: Open Your Terminal
Open a new terminal window on your machine (e.g., PowerShell, Command Prompt, or the VS Code integrated terminal) and navigate to the mobile app directory:

```bash
cd "c:\Users\DELL\Desktop\MMU STUDENT ATTENDANCE\mobile_app"
```

---

## 📦 Step 2: Install Flutter Dependencies
Ensure all package dependencies are downloaded and up to date by running:

```bash
flutter pub get
```

---

## 🔍 Step 3: Check Connected Devices
To see what devices are available on your system, run:

```bash
flutter devices
```

This will display a list of available targets (e.g., physical devices connected via USB, running Android emulators, Chrome, or Windows desktop).

---

## 🚀 Step 4: Choose Your Platform & Run

Depending on your preference, choose one of the following three ways to run the app:

### Option A: Run in Google Chrome (Web) — *Easiest & Fastest*
If you don't have an emulator or physical device set up, you can run the app directly in your web browser:
```bash
flutter run -d chrome
```

### Option B: Run on a Physical Android Device — *Best for QR Scanning*
1. Enable **Developer Options** and **USB Debugging** on your Android phone.
2. Connect your phone to your PC via a USB cable.
3. Make sure the phone is detected by running `flutter devices`.
4. Run:
   ```bash
   flutter run
   ```
   *(If multiple devices are connected, copy the device ID from `flutter devices` and run `flutter run -d <DEVICE_ID>`)*

### Option C: Run on an Android Emulator
1. Start your Android Emulator via Android Studio or VS Code.
2. Verify it is running by checking `flutter devices`.
3. Run:
   ```bash
   flutter run
   ```

## 🔗 Backend Connectivity Configuration (Optional)

By default, the mobile app is configured to talk to the live **Render Production Backend** (`https://mmu-attendance-backend.onrender.com`).

If you decide to run a **local Django backend** (`python manage.py runserver`) and want the mobile app to connect to it instead, follow these instructions:

### 1. Open the Constants File
The API URLs are defined in:
`mobile_app/lib/utils/constants.dart`

### 2. Update the `baseUrl`
Depending on which device you run the mobile app on, update the `baseUrl` at line 5:

| If running the mobile app on... | Set `baseUrl` to... | Explanation |
| :--- | :--- | :--- |
| **Android Emulator** | `'http://10.0.2.2:8000'` | Android emulators map `127.0.0.1` to themselves. Use `10.0.2.2` to access your PC's localhost. |
| **Chrome / Web Browser** | `'http://localhost:8000'` | Standard localhost URL since both run on your PC. |
| **Physical Android Device** | `'http://<YOUR_PC_IP>:8000'` | Set this to your computer's local IP address (e.g. `192.168.1.10`), and ensure both your PC and phone are connected to the same Wi-Fi network. |

## ❓ Troubleshooting

### 1. "flutter: command not found"
If you get this error, Flutter is not added to your system's Environment Variables PATH.
*   *Solution:* Download Flutter from [flutter.dev](https://docs.flutter.dev/get-started/install) and add the `bin` folder to your Windows system PATH.

### 2. QR Scanner Camera Permission (on Web)
When running on Chrome, the camera permission dialog will appear when trying to scan a QR code.
*   *Solution:* Allow Chrome to access your camera to successfully read the QR codes generated by the lecturer dashboard.
